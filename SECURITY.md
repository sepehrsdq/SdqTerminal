# Security Policy

## Supported versions

Security fixes are provided for the latest stable release of SdqTerminal.
Upgrade to the [latest release](https://github.com/sepehrsdq/SdqTerminal/releases/latest)
before reporting an issue when possible.

| Version | Security updates |
| --- | --- |
| Latest stable release (currently 1.1.2) | Supported |
| Older releases | Not supported; upgrade to the latest stable release |
| Development builds and prereleases | Best effort; no guaranteed security support |

## Reporting a vulnerability

Please report suspected vulnerabilities privately using GitHub's
[Report a vulnerability form](https://github.com/sepehrsdq/SdqTerminal/security/advisories/new).
Sign in to GitHub to submit a report and continue the discussion with the maintainers.
Do not publish exploit details in a public issue, pull request, or discussion
before the maintainers have had an opportunity to investigate.

Include the following when available:

- The affected SdqTerminal version and Windows version.
- The shell or application involved, such as CMD, PowerShell, WSL, or an interactive CLI.
- Steps to reproduce the issue and a minimal proof of concept.
- The expected and observed behavior, potential impact, and relevant logs or screenshots.

Remove passwords, tokens, personal data, and other secrets from any attachments.
Use test data when reproducing an issue.

## Review and disclosure

This is a community-maintained project. Reports are reviewed on a best-effort
basis; there is no guaranteed response or fix deadline. Follow-up questions and
status updates will be shared through the private GitHub report.

If a vulnerability is confirmed, the maintainers will coordinate a fix and public
disclosure with the reporter. If a report cannot be reproduced or is not considered
a security vulnerability, the maintainers will explain that assessment in the
private report when possible.

For ordinary bugs or feature requests that do not expose a security vulnerability,
use the [issue tracker](https://github.com/sepehrsdq/SdqTerminal/issues).
